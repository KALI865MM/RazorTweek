# Razor Tweek

A Windows desktop utility for monitoring system usage and applying optional performance and network settings.

## Download

Download **RazorTweek.exe** from the latest release. It is a single-file Windows build and does not require a separate Python installation.

## Features

- Live CPU, memory, disk, and network activity
- Optional power plan, Game Mode, visual effects, and DNS actions
- Startup entry management and temporary file cleanup
- Revert supported changes with **Undo All Changes**

Some actions, including restore points and changing DNS servers, require administrator access. Cloudflare DNS is optional. Review each selected action before applying it.

## Run

Download `RazorTweek.exe` from [Releases](https://github.com/KALI865MM/RazorTweek/releases) and open it on Windows.

Version: 2.0.0
